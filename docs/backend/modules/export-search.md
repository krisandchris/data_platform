# Export And Search API

Last updated: 2026-05-20

## Export Endpoints

| Method | Path | Request schema | Response schema | Permission |
| --- | --- | --- | --- | --- |
| `POST` | `/api/exports` | `ExportJobCreateRequest` | `ExportJobResponse` | export write boundary |
| `GET` | `/api/exports` | query filters | `ExportJobListResponse` | export read boundary |
| `GET` | `/api/exports/{export_id}` | none | `ExportJobResponse` | export read boundary |
| `GET` | `/api/exports/{export_id}/download` | none | file/download response | export read boundary |
| `POST` | `/api/exports/{export_id}/cancel` | none | `ExportJobResponse` | export write boundary |
| `POST` | `/api/datasets/{dataset_id}/exports` | `ExportRequest` | `ExportResponse` | export write boundary |

Design notes:

- Export jobs record source, filters, status, artifact file, and generated counts.
- Download endpoints must resolve only files generated by the export subsystem.

## Search Endpoint
